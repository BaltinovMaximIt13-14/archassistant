Условия использования

1. Настоящий сервис предоставляется "как есть" без каких-либо гарантий.

2. Ответы, генерируемые AI, носят рекомендательный характер и не являются официальными архитектурными решениями.

3. Пользователь несёт ответственность за проверку и валидацию всех архитектурных решений.

4. Запрещено использовать сервис для незаконных целей.

5. Мы оставляем за собой право изменять условия использования без предварительного уведомления.

Политика конфиденциальности

1. Мы не собираем и не храним ваши персональные данные.

2. История чатов хранится локально в базе данных на вашем сервере.

3. Загруженные файлы обрабатываются локально и не передаются третьим лицам.

4. Все запросы к AI обрабатываются локально через Ollama.

5. Мы не используем ваши данные для обучения моделей.
